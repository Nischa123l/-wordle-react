# Wordle React Clone

A functional Wordle-style word guessing game developed using React.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## Features

- Six rows and five letter tiles per row
- Physical keyboard input
- Interactive virtual keyboard
- Alphabetic input validation
- Five-character input limit
- Backspace functionality
- Enter submission functionality
- Green, yellow, and gray letter feedback
- Synchronized virtual keyboard feedback
- Win and loss conditions
- Game-over modal
- Restart functionality

## Installation

Clone the repository:

git clone YOUR-GITHUB-REPOSITORY-LINK

Install dependencies:

npm install

Start the development server:

npm run dev

## Production Build

npm run build
